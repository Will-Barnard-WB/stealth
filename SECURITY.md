# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately with GitHub's
[private vulnerability reporting](https://github.com/Will-Barnard-WB/stealth/security/advisories/new).
Include steps to reproduce and the potential impact if you can.

You should get an acknowledgement within a few days. We'll keep you updated while we work on a fix and credit you
when it's disclosed, unless you'd rather stay anonymous.

## Supported versions

stealth has no releases yet. Once it does, security fixes will go into the latest release.
